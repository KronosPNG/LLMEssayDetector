## 🎯 Overview

**LLM Essay Detector** is a classification system designed to tackle the growing challenge of AI-generated text detection in academic settings. As Large Language Models (ChatGPT, Claude, Gemini, DeepSeek) have become increasingly sophisticated, the need to distinguish between human-written and AI-generated essays has become critical for academic integrity.

This project implements a **hybrid dual-branch architecture** that combines:
- **Semantic embeddings** from SciBERT for deep contextual understanding
- **Stylometric features** for capturing writing style characteristics

### Key Results
- **Test Accuracy**: 99.92%
- **Balanced Performance**: 99.93% sensitivity (detecting AI), 99.92% specificity (detecting human text)
- **Minimal False Positives**: Only 4 false positives out of 5,199 human-written samples

## 💡 Motivation

The rapid advancement of LLMs has created a significant challenge in academic institutions: how to reliably detect when essays are AI-generated versus genuinely authored by students. Traditional plagiarism detection systems are insufficient for this task, as LLM-generated text is:
- Highly coherent and well-structured
- Free from natural human errors and variations
- Extremely difficult to distinguish from human writing

This project addresses the **Detection of AI-Generated Text (DAIGT)** problem specifically for academic essays, combining machine learning with natural language processing to achieve highly accurate classification.

## ✨ Key Features

- **Hybrid Architecture**: Combines semantic understanding with stylistic analysis
- **High Accuracy**: 99.92% test accuracy with minimal false positives
- **Interpretable Features**: 42 stylometric features provide insight into writing patterns
- **Robust Training**: K-fold cross-validation with optimal hyperparameters
- **Pre-trained Models**: Leverages SciBERT for academic text understanding
- **Genetic Algorithm Optimization**: Automated hyperparameter tuning
- **Ablation Study**: Comprehensive analysis of each component's contribution

## 🏗️ Architecture

### Overview

```

│                    Input Essay Text                         │
└──────────────────────┬──────────────────────────────────────┘
                       │
        ┌──────────────┴──────────────┐
        │                             │
        ▼                             ▼
┌──────────────────┐        ┌──────────────────┐
│ SciBERT Branch   │        │ Stylometric     │
│ Embeddings       │        │ Features (42)   │
│ [768-dim]        │        │ [42-dim]        │
└────────┬─────────┘        └────────┬────────┘
         │                           │
         └───────────┬───────────────┘
                     │
                     ▼
            ┌────────────────┐
            │ Concatenate    │
            │ [810-dim]      │
            └────────┬───────┘
                     │
                     ▼
            ┌────────────────┐
            │ Dense(512)     │
            │ + BatchNorm    │
            │ + Dropout(0.25)│
            └────────┬───────┘
                     │
                     ▼
            ┌────────────────┐
            │ Dense(256)     │
            │ + Dropout(0.25)│
            └────────┬───────┘
                     │
                     ▼
            ┌────────────────┐
            │ Dense(1)       │
            │ Sigmoid        │
            └────────┬───────┘
                     │
                     ▼
        ┌────────────────────────┐
        │ Output: 0-1            │
        │ (Human-AI Probability) │
        └────────────────────────┘
```

### Branch 1: SciBERT Embeddings

- **Model**: allenai/scibert_scivocab_uncased
- **Dimension**: 768-dimensional embeddings
- **Tokenization**: Intelligent truncation preserving first and last tokens for long texts
- **Pooling**: Mean pooling across all tokens

### Branch 2: Stylometric Features (42 features)

Captures writing style through:
- **Textual Complexity**: Sentence count, word length, paragraph structure
- **Punctuation Analysis**: Frequency of various punctuation marks
- **Readability Metrics**: Flesch Reading Ease, Flesch-Kincaid Grade
- **Morphological Features**: Uppercase ratios, title case distribution
- **Semantic Features**: Stop words, named entities
- **Lexical Diversity**: Type-token ratio, word repetition
- **Verbal Features**: Tense distribution, passive voice usage
- **POS Tags Distribution**: 19 Part-of-Speech tag frequencies

### Classification Layer

- Input: Concatenated features [810-dim]
- Dense(512, relu) + BatchNorm + Dropout(0.25)
- Dense(256, relu) + Dropout(0.25)
- Dense(1, sigmoid)
- **Optimizer**: Adam (lr=1e-4)
- **Loss**: Binary Crossentropy

## 🚀 Usage

### 1. Data Preparation

Prepare your training data and place it in `data/training_data/`:

```bash
python src/data_preparation/prepare_data.py
```

This script:
- Loads the DAIGT dataset
- Cleans and preprocesses text
- Creates embeddings and stylometric features
- Saves processed dataframes for training

### 2. Create Embeddings and Features

Generate SciBERT embeddings and stylometric features:

```bash
python src/create_embeddings_df.py
python src/create_feature_df.py
```

Output:
- `data/processed_datasets/embeddings_df.pkl` - SciBERT embeddings
- `data/processed_datasets/features_df.pkl` - Stylometric features

### 3. Train the Model

Train the hybrid model with K-fold cross-validation:

```bash
python src/train.py
```

**Configuration**:
- K-folds: 5
- Epochs: 10
- Batch size: 32
- Validation split: 20%
- Class weights: Automatically computed for imbalance handling

The best model is saved to `data/trained_model/model.h5`

### 4. Hyperparameter Optimization (Optional)

Run genetic algorithm for automated hyperparameter tuning:

```bash
python src/ga_optimize.py
```

This will:
- Evaluate different hyperparameter combinations
- Run genetic algorithm for optimization
- Save results to `data/ga_results/`
- Generate optimization progress charts

### 5. Inference - Test Your Own Essays

Use the trained model to classify new essays:

```python
from src.model.classifier import EssayClassifier

# Initialize classifier
classifier = EssayClassifier(
    model_path='data/trained_model/model.h5',
    scaler_path='data/trained_model/scaler.pkl'
)

# Classify essay
essay = "Your essay text here..."
prediction = classifier.predict(essay)

print(f"AI Probability: {prediction:.4f}")
print(f"Classification: {'AI-Generated' if prediction > 0.5 else 'Human-Written'}")
```

## 🔍 How It Works

### Detection Strategy

The model uses a two-pronged approach:

1. **Semantic Analysis** (SciBERT):
   - Deep contextual understanding of essay content
   - Captures semantic meaning and relationships
   - Pre-trained on scientific literature (relevant to academic essays)

2. **Stylometric Analysis** (42 features):
   - Identifies patterns in writing style
   - Detects characteristic AI writing patterns:
     - Excessive coherence and structure
     - Predictable punctuation usage
     - Specific vocabulary preferences
     - Consistent tense usage
     - Balanced syntactic complexity

### Why This Works

LLMs produce text with distinctive characteristics:
- Over-emphasis on certain transitional phrases ("moreover", "furthermore", "however")
- Balanced distribution of parts of speech
- Predictable punctuation patterns
- Low error rates and natural repetitions
- Consistent reading difficulty level

Human writers exhibit:
- Natural variation in writing style
- Occasional awkward phrasing or errors
- Diverse sentence structure
- Variable coherence patterns
- Unique personal writing habits

## 📈 Performance Metrics Explained

- **Accuracy**: Percentage of correct predictions overall
- **Sensitivity (True Positive Rate)**: Ability to correctly identify AI-generated essays
- **Specificity (True Negative Rate)**: Ability to correctly identify human-written essays
- **Balanced Accuracy**: Average of sensitivity and specificity (handles class imbalance)
- **F1-Score**: Harmonic mean of precision and recall

## ⚠️ Limitations

- Trained on English essays only (may have limited performance on other languages)
- Performance may degrade with new LLM architectures not in training data
- Works best with academic or formal essay-length text (not tweets or short social media posts)
- May have difficulty with adversarial inputs (deliberately obfuscated text)
- Requires minimum text length for reliable feature extraction (~500+ words recommended)
